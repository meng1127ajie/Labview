# JustFloat Studio

通用 C# / .NET 8 / WPF 上位机，支持J-Link RTT、TCP直连、J-Link HSS，以及独立的CAN报文/DBC分析工作区。

## 数据链路

```text
J-Link RTT 或 单片机/IDE TCP Server
        ↓
C# TcpClient（服务器IP + 端口 + 可选握手）
        ↓
JustFloat 动态帧解析
        ↓
原始字节记录 + 内存滚动历史 + 250 ms 图形刷新
```

连接方式：

- `J-Link RTT独立运行`：程序自动启动J-Link GDB Server、尝试continue目标，再连接RTT端口。
- `TCP直连 / IDE已启动`：不启动调试进程，只主动连接指定IP和端口。
- `HSS / ELF变量`：解析带符号信息的ARM ELF，搜索并选择RAM标量变量，通过J-Link SDK HSS后台采样后送入同一波形工作区。

## J-Link HSS / ELF变量

HSS使用流程：

1. 选择包含 `.symtab/.strtab` 的ARM `.elf/.axf/.out` 文件，也可以拖入窗口或作为启动参数打开。
2. 软件调用 `arm-none-eabi-readelf/nm`，只列出映射到可写RAM段的对象符号。
3. 在“选择变量”窗口中搜索变量、勾选变量，并确认数值解释类型。
4. 设置采样频率。连接时首先调用 `JLINK_HSS_GetCaps`，再校验探针支持的变量数量和最高频率。
5. 启动 `JLINK_HSS_Start`，循环读取 `JLINK_HSS_Read`，停止时调用 `JLINK_HSS_Stop/JLINK_Close`。

当前默认工具位置：

```text
C:\ToolChain\bin\arm-none-eabi-nm.exe
C:\ToolChain\bin\arm-none-eabi-readelf.exe
C:\Program Files\SEGGER\JLink_V952\JLink_x64.dll
```

注意：

- 1/2/4/8字节标量可以直接绘图；仅凭ELF符号大小不能可靠区分 `float/uint32/int32`，因此4字节变量默认按Float32解释，用户可以在变量窗口修改。
- 结构体和数组会出现在ELF目录中，但当前版本只允许直接选择标量。结构体成员展开留作后续增强。
- 建议被采样变量声明为 `volatile`，避免长期只保存在寄存器或被优化掉。
- HSS直接占用J-Link连接，不能与同一个探针的GDB Server/IDE调试连接同时使用。
- 正式HSS工作台只连接真实J-Link，不提供离线模拟开关；`SimulatedHssSession`仅保留在自动测试中验证解包、时间轴和统计链路。
- SDK头文件、PDF、LIB和压缩包不会复制到最终发布目录；程序运行时加载已安装的V9.52 DLL。

无硬件阶段已经验证：实际ELF解析、变量搜索/选择、HSS ABI导出检查、混合类型缓冲解包，以及测试工程中的1000 Hz模拟时间轴。正式程序只运行真实HSS；`GetCaps/Start/Read/Stop` 返回值、探针能力和长期稳定性等待接板验证。

TCP直连参数：

- 数据引擎：`JustFloat`
- 数据接口：`TCP客户端`
- 服务器IP：默认 `127.0.0.1`
- 端口：默认 `19021`
- 握手数据：默认 `plot0`，可留空；支持输入 `\r`、`\n`、`\0`
- 通道数：`0` 表示自动检测，也可以手动指定

## JustFloat协议

每帧为 `N × little-endian float + 00 00 80 7F`。

- `N` 支持4~1024。
- 自动模式使用连续三个等间距帧尾识别帧长。
- 即使负载中也出现 `+Inf/0x7F800000`，仍通过帧间距和SEQ/TIME_MS校验排除假帧尾。
- 当前固件约定索引0为SEQ、索引1为TIME_MS；自动识别使用这两个字段做可靠性校验。
- 未加载Excel模板时，所有通道只显示为 `CH_0、CH_1……`。二进制流本身不包含变量名称、单位和分组，软件不会猜测含义。
- 首次启动时信号目录为空；加载Excel后按模板建立目录，或收到/载入有效帧后按实际通道数量建立 `CH_N` 目录，不预建固定样本。

项目不依赖内置BIN样本，也不包含扫频诊断页面；仍支持记录原始BIN和加载任意BIN离线查看。

## CAN报文分析

启动中心点击“CAN工作台”进入独立CAN窗口。窗口分为互不混用数据缓存的“在线监控”和“离线分析”页面；二者共享DBC数据库、报文浏览和波形工具。CAN数据先统一成 `时间、通道、ID、标准/扩展帧、方向、CAN/CAN FD、DLC、Data`，随后再由DBC可选解码信号。

当前支持：

- 离线读取Vector二进制 `.blf`、Vector `.asc`、SocketCAN/candump `.log`，以及同类 `.txt/.csv` 文本报文。
- 经典CAN、29位扩展帧、Remote帧和常见Vector CAN FD文本行。
- 在线监控可直接打开ZLG硬件：选择设备型号/索引/通道、经典CAN或CAN FD、仲裁/数据波特率、只听模式和内部120Ω后连接。
- 发布包内置用户提供的官方x64 ZLGCAN用户态运行库，固定放在 `Drivers\CAN\ZLG\x64\runtime`；不再依赖ZCANPRO脚本或19023桥接端口。目标电脑仍须安装与硬件匹配的官方Windows设备驱动。
- 网络CAN作为独立通用数据源保留。默认 `127.0.0.1:19022`，服务器每行发送一帧即可。
- 在线状态同时显示原始字节数、有效文本行、成功解析帧和格式失败数。TCP只握手但没有CAN数据、收到二进制而非文本、缺少换行或行格式不兼容时，都能直接区分，不再只显示笼统的“已连接”。
- 未加载DBC时，按实际DLC自动提供 `Byte0~Byte63` 原始字节信号，仍可直接绘图。
- 可同时加载多个DBC；后加载文件优先，同ID覆盖会明确显示冲突数量。下拉框列出每个DBC并可移除。
- 加载DBC后显示报文名、信号名、最新物理值、单位、位定义、枚举文本及该帧实际接收频率。
- 报文目录同时包含DBC已定义但尚未收到的帧，以及已经收到但DBC未定义的帧；可按“全部、已接收、DBC定义、DBC未定义”筛选。
- 通过十六进制ID、报文名、Data、信号名或单位搜索；报文和信号均可加星标，并可只看标记项。
- 最多同时绘制8个信号。信号默认进入图1，用户通过“+图”和信号右侧图号手动分配到最多4个坐标图。
- CAN与J-Link波形采用一致操作：指针、点选采样、双游标 `Δt/ΔY`、框选放大、右键平移、滚轮缩放、适配Y、活动图最大化、采样点和PNG导出。
- 时间窗口默认“全部”；多图太小时可点击“最大化”只查看当前蓝框图，再点击“显示全部”恢复。
- CAN右侧默认使用“波形”视图，让图形占满分析区域；“报文”视图让原始帧表占满区域；只有需要对照时才选择“分屏”并拖动上下分隔条。
- “专注波形”会收起左侧报文/信号目录，让多图使用整个窗口；左侧目录在普通模式下也可以拖动调整宽度。
- 左侧报文ID与信号目录之间也有可拖动分隔条；在线帧到达但尚未选择曲线时，底部会明确提示“选择ID并勾选信号”，避免把“未选信号”误认为没有接收到报文。
- 在线页使用“清空接收缓存”：不断开硬件，清空历史、统计和波形后继续接收。离线页使用“关闭数据集”：移除当前日志数据但保留DBC。共享“清理 ▾”只包含取消绘图信号、清除A/B游标和恢复视图。
- 多个日志可选择“保留原始时间、紧接上一段、按指定间隔追加或替换当前数据”；不同段之间绘图自动断线，避免产生不存在的连接线。
- 内存最多保留最近1,000,000帧；原始报文表只虚拟化显示最近3000行；单信号最多保留200,000个绘图点并在渲染时降采样到50,000点。

在线TCP输入支持以下常用行格式：

```text
123#11223344
(1712345678.123456) can0 18FF50E5#11223344
0.123000 1 123 Rx d 4 11 22 33 44
0.123000,1,123,Rx,11223344
```

第一种紧凑格式没有时间戳，软件使用连接后的单调计时；其余格式保留输入时间。厂商USB-CAN驱动通过 `ICanFrameSourceFactory/ICanFrameSource` 插件接口扩展，所有适配器最终输出统一 `CanFrame`，因此后续接PCAN、Vector、Kvaser、SLCAN或SocketCAN时不需要修改DBC、原始报文和绘图层。当前发布版启用ZLG与虚拟测试适配器，未实物验证的厂商插件不会冒充“已检测设备”。

示例文件：

```text
Samples\CAN\demo.dbc
Samples\CAN\demo.asc
```

可将多个DBC以及BLF/ASC日志一起拖入CAN窗口，也可以把它们作为启动参数传给程序。

## DBC可视化制作器

CAN窗口点击“制作DBC”可以新建或修改报文和信号，并保存为标准文本DBC。

- 报文：ID、11/29位、名称、DLC（1~64字节）、周期和发送节点。
- 信号：名称、StartBit、长度（1~64位）、Intel/Motorola、有符号、Factor、Offset、Min、Max、单位和基础Multiplexer。
- Intel / Little Endian对应DBC `@1`：StartBit指向信号LSB，原始值bit 0、1、2……按全局位号递增。
- Motorola / Big Endian对应DBC `@0`：StartBit指向信号MSB，同一字节向Bit 0移动，跨字节后跳到下一Byte的Bit 7。
- 右侧Byte/Bit图按行显示Byte、按列显示Bit 7~0；格内 `#0、#1……` 是实际读取顺序，而不仅是物理bit编号。
- 青色表示当前信号，蓝色表示其他信号，红色表示重叠；点击任意bit可直接设置当前信号StartBit。
- 保存前检查越界、非法系数、重复ID、重复信号名和非Multiplexer重叠。
- 读取已有DBC再保存时保留注释、枚举、接收节点、数值类型和周期等已解析信息。

首版解析常用的 `BO_ / SG_ / VAL_ / CM_ / GenMsgCycleTime / SIG_VALTYPE_`，支持基础复用信号。复杂的 `SG_MUL_VAL_` 扩展复用范围尚未编辑，遇到此类DBC应使用原始文件备份并在专用DBC工具中复核。

## Excel信号模板

自动协议检测只能得到float数量，不能从二进制流推断字段名称、单位、分组和图号。点击“选择Excel…”加载配置；也可把 `.xlsx/.xlsm` 拖入窗口，或作为启动参数打开。

工作表优先使用 `Signals`，否则读取第一个工作表。第1行必须包含：

```text
Index | Key | DisplayName | Unit | Group | Visible | PlotGroup | Color | Format | IntegerLike
```

- `Index`：从0开始，不能重复。
- `Visible`：1/true/yes/是/显示表示默认绘图。
- `PlotGroup`：1~8。
- `Color`：`#RRGGBB`，可留空。
- `Format`：例如 `F3`、`F5`、`G7`。
- `IntegerLike`：状态量填true后使用阶梯线。

加载模板后，实际协议通道数仍由数据流自动检测；模板按Index覆盖字段信息，未配置的通道仍显示为 `CH_N`。

## 模块化启动中心

程序启动后首先显示小型启动中心，不再把所有参数和图表堆在一个窗口中。三个入口按真实工作流划分：

- “J-Link数据采集”：下拉选择RTT、TCP或真实HSS/ELF；收到信号后在同一工作台进入波形分析。
- “CAN工作台”：在线硬件/网络监控与离线BLF/ASC分析分成独立页面，ID和信号搜索、DBC加载解码及多图曲线复用同一组件。
- “DBC制作器”：独立创建或修改DBC以及Intel/Motorola Byte/Bit布局。

连接设置与波形属于同一工作流：波形页返回时先回到连接设置，再返回启动中心，符合“返回上一个位置”的导航习惯。CAN和DBC制作器是独立工具。工作台实例会被复用，因此返回不会主动停止后台采集，也不会丢失当前缩放、游标和信号选择。

启动参数与拖放会自动路由：BIN进入采集工作台内的波形页，Excel/ELF进入连接设置，DBC/BLF/ASC进入CAN分析。`Ctrl+1 / Ctrl+2 / Ctrl+3`分别打开连接设置、波形和CAN；没有信号时波形入口保持禁用。

## MATLAB式波形工作区

左侧信号目录：

- 加载模板后按Excel的 `Group` 列分组折叠；仅从数据识别出的未配置通道统一放在“未配置”组。
- 复选框控制是否绘制。
- 每个信号可分配到图1~图8。
- 点击“＋图”新增坐标图；新增图会成为活动图。
- “清理 ▾ → 取消全部信号勾选”只取消绘图，不删除配置、图组和已接收数据。
- “清理 ▾ → 清除数据”清除内存中的实时/BIN历史、波形和统计，保留Excel信号配置、勾选状态以及磁盘上的BIN文件；连接中使用时会从零重新累计后续数据。
- 同一菜单还提供“清除A/B游标”和“恢复活动图视图”，工具栏不再散落多个含义相近的清除按钮。
- 在活动图选中后，新勾选的信号自动进入该图。
- 组号下拉框可以随时把信号移动到其他图。

右侧坐标图：

- 同组信号共用一个坐标图和Y轴。
- 多个坐标图共享TIME_MS时间轴。
- 左键点击选择活动图，蓝框表示当前活动图。
- “指针”和“点选采样”是互斥模式，当前模式保持蓝色高亮；默认进入指针模式。
- 指针模式下，鼠标移动到曲线上会吸附最近采样点，图内数据框持续显示TIME、SEQ和变量值；实时刷新不会清掉指针。
- 任意模式下按住鼠标右键拖动即可平移坐标范围，并自动关闭“追踪最新”，因此不再需要单独的平移按钮。
- “点选采样”会自动暂停显示；左键点击后用实心点锁定最近采样点，数据框持续显示该点，直到重新点选、切换工具或继续实时显示。
- 点选采样锁定A游标后，可用键盘←/→逐采样移动；开启“双游标”后再次左键放置B游标，Tab切换活动A/B游标。图内同时显示两条竖线，并计算 `Δt=B.time-A.time`、`ΔSEQ`，以及每个已选信号的 `ΔY=B-A`。
- 必须先左键选中坐标图（蓝色边框）才响应滚轮；未选中的图上滚轮不改变任何坐标范围。
- 活动图中，滚轮向上放大、向下缩小；放在X轴区域时只缩放X轴，放在Y轴区域时只缩放Y轴，放在图内同时缩放XY。缩放围绕鼠标位置进行，并兼容高分辨率滚轮增量。
- “框选放大”模式下按住左键拖出矩形范围进行放大；右键拖动平移在所有工具模式下保持可用。
- 工具栏精简为指针、点选采样、双游标、暂停、恢复视图、最大化活动图以及显示选项；缩放统一使用滚轮。
- “最大化活动图”只显示当前蓝框图，再次点击“显示全部图”恢复多图布局。
- 手工缩放后关闭“追踪最新”，防止实时刷新把视图强行拉回。
- 鼠标移动显示最近采样点的SEQ、TIME_MS和各信号值。
- 绘图模式切换只改变图表交互，不会停止或重新连接RTT/TCP/HSS采集会话。
- “暂停显示”会保留当前波形快照供指针、右键平移、滚轮和时间窗口分析；后台采集与统计继续运行。“继续显示”会释放快照并回到最新实时波形。
- 分析窗口右上角关闭或按Esc只返回启动中心；应用不会退出，采集和记录继续。只有在启动中心关闭并确认“安全退出”后，才显示关闭遮罩，阻止重复操作，并依次停止RTT/HSS/CAN接收、刷新并关闭BIN记录、断开TCP，再退出由本程序启动的J-Link GDB Server进程树；不会结束用户在外部启动且仅被本程序附加的J-Link服务。

## 帧率与丢帧统计

- “实时 / 平均帧率”左侧为最近2秒接收帧率，右侧为从首个有效帧开始的全程平均值，连接等待时间不计入均值。
- 软件不会再固定假设SEQ必须每帧+1；至少观察到3次相同增量后才确认正常SEQ步长。
- 例如固件SEQ为 `0,100,200,300...` 时，正常步长确认为100，不会把每帧误报为丢99帧。
- 只有跳变为已确认步长的整数倍时才计算缺失帧；非整数跳变计入“异常”，SEQ回退单独计入“重启”。
- 丢帧率分母为 `实际接收帧 + 确认缺失帧`，并同时显示缺口事件数、SEQ步长、异常数和重启数。
- HSS由探针定时，没有固件SEQ，界面显示实际采样率与探针GetCaps能力，不套用RTT的SEQ丢帧算法。

## “收到多少，处理多少”

- RTT和TCP收到的原始字节都可全部写入BIN记录文件，不经过UI抽样。
- 每一个成功解析的帧都会进入统计与数据事件。
- 图形按250 ms节流刷新，避免接收线程被UI阻塞。
- 为防止长时间运行耗尽内存，图形内存保留最近200,000帧；这不影响原始文件记录和累计接收统计。
